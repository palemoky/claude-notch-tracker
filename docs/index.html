Why you'll keep it

📊 Real limit tiles

The same bars the official apps show — 5-hour, 7-day, weekly caps — each with a reset countdown and urgency colour.

🔄 Five providers, one click

Claude, Codex, Antigravity, DeepSeek and opencode-go. Click the icon to cycle; only installed ones appear.

🦀 Clawd the crab

He quickens as you approach a limit and freezes when you're out. Mono and Spark looks included.

🔒 Local-first

Reads your local sessions and talks only to first-party services. No analytics, no third-party servers.

🌙 Hide in full screen

Optionally tucks into the notch while movies and video own the display.

✨ Zero fuss

No Dock icon, no menu-bar clutter. Draws its own notch on non-notch Macs, updates itself.

Install in a minute

  1. Download Claude Notch.zip from Releases, drag to Applications.
  2. Double-click to open. On the Keychain prompt, choose Always Allow so it can read your local session.
  3. Right-click the island → Launch at Login to keep it around.
git clone https://github.com/stevemcqueenz/claude-notch-tracker
cd claude-notch-tracker
swift run ClaudeNotch   # needs full Xcode
